# Brodie creators — send kit

Recruiting email for beginner content creators, in the getbrodie.com brand.

## Send it

1. Open https://hmm76.github.io/brodie-creator-kit/
2. Click **Copy email**, paste into a new message in Gmail / Apple Mail / Outlook.
3. Click **Copy subject**, paste as the subject.
4. Send.

Got it as an email? Forward it. The header, the proof row and the button survive forwarding.

## Files

- `index.html` — the email with the Copy buttons
- `hero_banner.jpg` — 1200×700 header, Archivo 800 on #0a0a0b with the acid line, served from this repo
- `make_header.py` — regenerates the header (needs `assets/fonts/Archivo.ttf` + `PlusJakartaSans.ttf`)

Brand reference: `docs/BRAND.md` in the carousel-engine repo (palette, type, components, voice, all measured from getbrodie.com).
